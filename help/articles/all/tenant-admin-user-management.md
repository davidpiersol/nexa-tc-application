## Tenant Admin: User Management

Use the Users area to manage the people inside your tenant without widening access beyond what each person actually needs.

### Creating and editing users

1. Create the account with the user’s normal starting login type.
2. Open the user profile when you need to update contact details, password actions, role group, or login permissions.
3. Keep the **active login type** aligned with the workspace the person should enter by default.

### When one person has more than one job

Some people genuinely work in more than one lane—for example, a tenant admin who is also a TC or broker.

1. In that user’s profile, check every **Allowed Login Type** they are permitted to use.
2. Leave only the roles they should truly be able to enter.
3. The user can then switch among those allowed login types from the account menu.

### Important distinction

- **Allowed Login Types** = the workspaces a person may enter.
- **Active Login Type** = the one workspace they are acting as right now.

The system uses one active login type at a time so permissions stay deliberate rather than blended.

### Good practice

Give users the narrowest practical set of allowed login types, then add more only when their real work requires it.

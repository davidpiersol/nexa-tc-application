# CRM Workspace

The **CRM** workspace is your personal follow-up center. It does not replace the canonical **Contacts** and **Brokers** directories; it links activity back to those records.

## Start with Upcoming Actions

Use the landing page to answer four practical questions:

1. What needs attention **today**?
2. What is due **this week**?
3. What is coming **this month**?
4. What should stay visible for **this quarter**?

## CRM sections

- **Tasks**: add follow-up work with a due date, priority, status, and linked contact.
- **Reminders**: add dated nudges that should roll back into Upcoming Actions.
- **Touches**: log calls, emails, texts, meetings, and the outcome or next action.
- **Notes**: keep private CRM context without creating a follow-up task.
- **Relationships**: connect two existing contacts when the relationship matters to future business.
- **Segments**: review SOI, hot/warm/cold, broker client, vendor, prospect, and similar groupings.
- **Calendar**: scan dated work in calendar form.
- **Import / Export**: use CSV and vCard entry points when moving contact data in or out.
- **Connections**: review external CRM candidates and whether setup is still pending.

## What to do on each page

1. On **Upcoming**, start with overdue work, then today, then this week.
2. On **Tasks**, open the task detail before editing so you can confirm the right contact and due date.
3. On **Reminders**, use reminders for “remember to do this” items; use tasks when actual work needs to be tracked.
4. On **Touches**, record what happened after a conversation so the next action is not trapped in memory.
5. On **Notes**, save durable context you may need later even when no next step is due.
6. On **Relationships**, link existing people; do not recreate them.
7. On **Segments**, check whether the contact’s working category still matches how you intend to follow up.

## Contact handling

When a CRM record needs a person, search for an existing contact instead of scrolling a long list. If the person does not exist yet, create them in **Contacts** first, then return to CRM and link the activity.

## Good daily rhythm

1. Open CRM at the start of the day.
2. Clear overdue items first.
3. Log touches as you complete them.
4. Add the next task or reminder before closing the contact loop.

## External CRM boundary

Connections are planning surfaces until credentials, consent, field mapping, duplicate handling, and provider rules are approved. No external CRM sync runs just because a provider appears on the page.

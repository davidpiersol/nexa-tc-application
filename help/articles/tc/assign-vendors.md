# Assign Vendors to a Transaction

Use **Assign Vendors** inside a transaction workspace to attach service providers without duplicating contact records.

## What this workflow does

- Reuses existing records from your Contacts directory.
- Adds a transaction-specific assignment role (Vendor, Lender, Title, Attorney, Broker, or Other).
- Optionally stores category context and assignment notes for this transaction only.
- Leaves canonical contact profiles unchanged.

## Steps

1. Open a transaction.
2. Click **Assign Vendors** in the transaction workspace navigation.
3. Select a contact from service-provider categories.
4. Choose the assignment role for this file.
5. Optionally add category context and notes.
6. Click **Assign vendor**.

## Remove an assignment

Use **Remove** on any assigned row. This only removes the transaction link and does not delete the contact profile.

## Where assigned contacts appear

Assigned providers are listed on:

- The **Assign Vendors** page (full manage view)
- The **Transaction detail** page (quick visibility)

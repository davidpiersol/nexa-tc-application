## Broker Profiles

The **Brokers** workspace is a filtered view of contacts that include the `Broker` category.

### Broker-specific fields

1. Brokerage selection.
2. Signing platform.
3. Signing preference.
4. Credential update controls (admin-restricted).

### Recommended usage

1. Keep person details in the base contact record.
2. Keep broker operations fields on broker profiles only.
3. Use the broker list for quick lookup, edit, and delete operations.

### Upcoming company linkage

Brokerage values are currently selected directly in profile fields. Company-level normalization is scaffolded and can be expanded into a reusable CRM company model.

# Optional rule packs (`rules/`)

This folder follows the [awesome-cursorrules](https://github.com/PatrickJS/awesome-cursorrules) idea: add technology-specific **`.cursorrules`** files in subfolders when you import or author stack-focused rules.

Recommended folder naming from that project: `technology-focus-cursorrules-prompt-file`.

The repository already includes modern **`.mdc`** starters under **`rules-new/`** (same format as upstream). Copy or symlink the files that match your stack into `.cursor/rules/` or keep them here for reference.
